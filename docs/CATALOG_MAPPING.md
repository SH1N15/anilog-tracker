# 季度目录与运行时映射

适用版本：v0.7.6（从 v0.7.6-rc.1 引入）。本契约补充 [AniList 请求策略](ANILIST_REQUEST_POLICY.md) 和 [观看状态回归](WATCH_STATE_REGRESSIONS.md)。

## 换季不依赖重新发包

标准版仍用 Bangumi 作为季度目录与逐集身份来源。编译进程序的 bangumi-data 仅提供初始关联，不能作为新季度必须具备的依赖，也不能通过硬编码季度、作品 ID 或日期补丁修复目录。

有未关联条目时，季度刷新使用同年同季的 AniList 目录补充身份：

- 标题忽略大小写与标点后完整相等，保留续季、分篇编号；不以包含关系或模糊分数自动关联。
- 类型必须相同；两边均须有年、月。日期完整时最多容许一天差异，以兼容跨时区首播日期；日期缺日时要求同年同月。不以缺失日期或仅年份作为可靠证据。
- 两个目录中都必须唯一匹配。已明确关联的分篇可以共用 AniList ID，但自动发现不能把有歧义的分篇合并。
- 季度发现可以覆盖 TV、电影、ONA、OVA；不要求 bangumi-data 同时具有两个站点 ID，也不要求它预先收录作品。
- 季度目录复用原有缓存、批量结果、速率限制与退避。仍只在查看季度或明确刷新该季度时拉取，加入一部追番不得触发全季度网络请求。
- 目录结果同时填充 AniList 逐作品缓存，保留实际获取时间。失败不把旧缓存重新记为刚获取。

Bangumi 季度缓存增加 `catalogRevision=2`。升级时先显示旧快照，再在后台刷新旧格式缓存，不需要用户清缓存。成功发现的关联可在下次网络失败时保留；关联记录不能为旧播出时间续期。

## 播出日与精确日程分开

有有效日程时按其精度展示与分组。没有日程时，可以使用 Bangumi 明确公布的放送星期或完整首播日期作为目录展示依据，显示“首播 … · 时刻待定”；真正无日期才进入“播出日待定”。

精确时刻转换为设备时区。日期级数据使用来源日历，不构造午夜时刻，不跨时区移动日期，不据首播星期推算每集。目录日期与 `broadcastWeekday` 不生成观看任务或通知。

## 旧追番的映射恢复

标题缓存中的 `bangumiId` 只是候选证据，不等同于正式迁移。调度前对无正式 mapping 的旧记录读取该 subject 的公共详情，使用完整标题、类型和日期再次核验，再复用已有迁移函数：

- 主键切换为 Bangumi subject，保留 AniList ID。
- 清除待确认标记，重新用逐集接口生成本机日程。
- 已完成记录原样保留；待看任务按既有主键迁移、去重和墓碑规则处理。
- 已有手动选择或用户明确跳过的低置信度 mapping 不被覆盖。已占用的目标主键或不一致的候选不强行合并。
- `mappingPending=true` 不再阻止新离线证据重新评估。已有季度缓存也可为后续跨端到达的追番补充关联，无需再访问季度网络接口。
- 公共详情核验缓存保留 24 小时；手动刷新有 60 秒下限；失败也保留 60 秒退避。检查时重新读取当前状态，避免用请求开始前的快照覆盖用户取消或修改的记录。

此逻辑在共享 Rust 层执行。Windows 调度、Android 前台同步与新追番入口均接入；迁移后的完整记录继续通过既有 Android 桥和 WebDAV 业务文档传递。缓存、设备设置与凭据不进入 WebDAV。Android WorkManager/AlarmManager 的后台频率不变。

Original 不编译运行时 Bangumi 映射模块，也不调用 Bangumi；共用日期级展示仅使用它自己的 AniList 数据。

## 验证入口

- [共享映射与模拟 HTTP 测试](../src-tauri/src/catalog_mapping.rs)：空离线表、跨季度跨年、类型差异、续作及分篇歧义、缓存复用、旧缓存升级、待确认恢复、用户跳过、完成历史、单条追番请求范围。
- [日期与星期展示测试](../scripts/test-season-grouping.cjs)：2026/2027/2032 年四个季度，UTC、中国、美国西岸时区，缺失与无效日期，日期级数据不生成集事件。
- 常规门禁仍运行两个 Cargo edition、两个 Android JVM edition、Node 回归和双端构建。
- `live_catalog_audit` 默认忽略。人工验证时在独立目录提供 `input.json` 业务数据投影，设置 `ANILOG_CATALOG_AUDIT_DIR` 后显式运行 `cargo test --manifest-path src-tauri/Cargo.toml --features standard live_catalog_audit -- --ignored --nocapture`。它只访问公开读取接口，输出目录快照和迁移预览；输入不得含凭据，目录不得指向运行中应用的数据目录。

本次没有覆盖或硬修 AniList 的任何作品时间。分钟级上游错误仍按其响应呈现，不能把某部作品的差值推广成通用时区补丁。
