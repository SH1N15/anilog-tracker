# AniLog v0.7.3

## 重点修复

- 修复 Android 季度新番缓存过大、WebView 配额失败后重启丢失的问题；旧缓存会迁移为压缩快照。
- 修复季度缓存过期时首屏被 Bangumi 多月分页和 AniList 补充请求阻塞的问题：先显示可信旧数据，再后台刷新。
- 修复 Android 新番详情页在窄屏设备上的横向溢出；统计、Bangumi 详情、长标题和操作按钮现在会自适应换行。
- 保留 v0.7.2 的 Bangumi 分季本地集号、观看任务清理、分钟级时间匹配和 WebDAV 愈合修复。

## 升级提示

覆盖安装前建议启用 WebDAV 或备份 Windows 安装目录中的 `data` 文件夹。WebDAV 只同步追番、观看任务和取消追番记录，不同步缓存、设置或凭据。
