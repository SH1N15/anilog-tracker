# AniLog v0.7.4-rc.1

2026-09-10 的本地测试构建记录；该 rc 未创建公开 Release，也未替换当时的正式版 `v0.7.3`。维护者于 2026-09-13 确认测试通过；后续正式发布见 [`v0.7.4`](v0.7.4.md)，不要将这里的 rc 文件或校验值作为正式附件。

## 修复内容

- 修复 Re0 等分篇作品共用 AniList ID 时，另一篇章的待看任务被误删。
- 修复 Android 日期级日程触发提前通知，以及跨午夜后合法待看任务消失。
- 修复 Android 前后台精简记录丢失任务时间戳，以及同步覆盖本机日程。
- 修复勾选、撤销任务后追番进度不更新，以及“在看”进度未随 Bangumi 拉取刷新。
- 自动补回的待看任务不能覆盖已完成记录；两端都需升级以采用一致的合并规则。
- 修复手机追番进度被挤成竖排，日期级日程不再展示虚构的精确时刻。

## 安装与验证

- Android `versionCode=12`，仅支持 `arm64-v8a`。
- Windows 安装包没有商业代码签名，系统可能显示“未知发布者”。
- 安装前备份 Windows 安装目录的 `data`。Android 应直接覆盖安装，不要先卸载。
- 请同时升级 Windows 和 Android 对应 edition，再进行双向同步和通知复测。
- 自动测试和编译检查不能替代真机的跨午夜、进程回收及厂商后台调度验收。
