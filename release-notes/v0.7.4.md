# AniLog v0.7.4

## 重点修复

- 修复 Re0 等分篇作品共用 AniList ID 时，另一篇章的待看任务被误删。
- 修复 Android 将日期占位当作午夜播出时间而提前提醒，以及跨午夜后合法待看任务消失。
- 修复手机前后台传递精简记录造成时间戳丢失，以及旧快照或 WebDAV 合并覆盖本机日程；更新时间不再因这些路径反复回到待定。
- 修复勾选、撤销任务后追番进度不更新，以及“在看”进度未随 Bangumi 拉取刷新。
- 自动补回的待看任务不再凭较新的生成时间覆盖已完成记录；手动撤销仍可正常同步。
- 修复手机追番页进度文字被挤成竖排，日期级日程不再显示虚构的精确时刻。

## 升级提示

- **请同时升级 Windows 和 Android 对应 edition**，两端使用一致的任务合并规则。
- Windows 安装前备份安装目录的 `data`，退出程序和托盘后覆盖安装。
- Android 直接覆盖安装，不要先卸载。正式版 `versionCode=13`，高于 `v0.7.3` 的 `11` 和本地验收版 `v0.7.4-rc.1` 的 `12`。
- Standard 与 Original 保持不同包名；Android 正式附件仅支持 `arm64-v8a`，使用既有发布证书签名。
- Windows 安装包没有商业代码签名，系统可能显示“未知发布者”。

## 验收与边界

维护者于 2026-09-13 确认本地候选版测试通过。本次使用正式版本号重新构建，
保留 Tauri 2 正式架构和旧 Electron/Capacitor 回退实现。

WebDAV 仍只同步追番、观看任务和取消追番记录，不同步缓存、设备设置或凭据。
Android 后台仍依赖 WorkManager/AlarmManager，厂商省电策略可能延迟执行。
AniList 不可用时保留可信精确缓存或日期级信息，不按周播锚点猜测提醒时刻。
