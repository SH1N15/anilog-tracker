# AniLog v0.7.5-rc.3

本地测试候选版，未公开发布。GitHub Latest 仍为 v0.7.4。

## 修正

- 已有逐集证据确认“尚未播出”的旧完成记录保留到“待核对”，不再计入已看数量、完成率和观看进度。
- 保留原始观看记录和时间戳，不自动删除历史或撤销云端记录；可以明确选择确认已看或撤销异常完成。
- 撤销后保留核对信息，在实际播出前不进入待看计数，旧设备同步也不会重新恢复错误完成。
- 旧完成记录缺少本地操作来源时不再自动推送；待核对记录禁止写回，发送前和成功记账时复核任务版本。
- 本次不更改延期日期，不按每周周期猜测下一集。仍以最新上游逐集数据为准。
- 保留 rc.1/rc.2 的取消追番、同步冲突、缓存与冷启动修正。

## 安装与验收

- Windows 和 Android 请同时覆盖升级对应 edition。Windows 先备份 `data` 并退出应用和托盘。
- Android `versionCode=17`，仅 `arm64-v8a`，沿用既有发布证书。直接覆盖安装，不要卸载。
- 本版本不能直接覆盖降级到 code 16 或更早；Windows 安装器仍可能提示“未知发布者”。
- 本轮反馈场景应恢复为 11/13；异常第 13 集从正常已看列表转入“待核对”，未核对前不会上传。
- “撤销异常完成”保留旧记录信息；开启进度上传时，会在后续同步撤销对应集的云端已看状态。只有你实际看完时才选“确认已看”。
- 真机覆盖升级、强制停止后重开和跨端同步仍需维护者验收；没有改动已安装应用、真实本地数据或云端收藏。

回归契约见 [观看历史与同步](../docs/WATCH_STATE_REGRESSIONS.md)。

- Windows 两版安装程序已核对产品名称及 `0.7.5-rc.3` 版本。
- Android 两版已核对包名、`0.7.5-rc.3` / code 17、既有发布证书、ARM64 单 ABI 和 16 KB ZIP 对齐。
- 未连接可用的 ADB 真机；以上检查不代表真机覆盖升级、厂商后台调度或真实账户跨端同步已经验收。
