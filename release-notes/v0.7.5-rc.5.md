# AniLog v0.7.5-rc.5

本地候选版，未公开发布；GitHub Latest 仍为 `v0.7.4`。

## 本轮修复

- 修复 Windows 上 Bangumi 反代始终显示无法连接的问题。Tauri Rust HTTP 客户端显式启用 reqwest `system-proxy`：Windows/macOS 配置了系统代理时跟随系统代理，系统代理关闭时继续直接访问反代，不把 VPN 设为应用硬依赖。
- 测试 mock 客户端在单元测试中强制直连本地服务器，避免开发机系统代理干扰网络错误断言；生产客户端仍保留系统代理发现。
- 增加网络客户端代理契约回归检查，防止后续依赖清理时误删 `system-proxy`。
- Android `versionCode` 递增到 `19`，四件产物独立保留，不覆盖 `v0.7.5-rc.4`。

## 真机验收重点

1. Windows 覆盖安装 rc.4，保留原安装目录下的 `data`。
2. Android 覆盖安装 rc.4，不卸载、不清除数据；Standard 与 Original 不要混装。
3. 系统代理/VPN 开启时测试 Bangumi“测试并保存”。
4. 关闭 VPN，并在 Windows 系统设置中确认系统代理也已关闭，再重启 AniLog 测试同一反代；此时应走直连，不应要求 VPN。
5. 若 VPN 关闭后系统代理仍保留为 `127.0.0.1:7897`，应用仍会按系统设置尝试该代理，这不是直连测试状态。
