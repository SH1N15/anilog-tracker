# AniLog v0.7.6-rc.1

本机验收候选版，尚未发布到 GitHub。正式 Latest 保持 v0.7.5。

修复新季度作品全部进入“播出日待定”和旧追番长期“待确认映射”的问题：

- 标准版在运行时通过 Bangumi/AniList 季度目录核验关联，不再要求内置旧映射表预先收录新季度作品；覆盖跨季、跨年及电影、网络动画等类型。
- 已公布日期但缺少精确时刻的作品显示首播日期和“时刻待定”。日期级信息不创建精确通知，也不按周推算集数。
- 旧追番已有 Bangumi 候选时自动核验标题、日期和类型，确认后完成主键迁移；保留已完成观看历史、手动选择、主动跳过和存在歧义的记录。
- 升级后旧季度快照先显示、后台更新，不需要清空缓存或用户数据。
- Original 保持不访问 Bangumi。未对 AniList 上游时间做作品级补丁。

## 安装包

- Windows Standard / Original：x64 NSIS 安装器。
- Android Standard / Original：仅 arm64-v8a，versionCode=22，沿用正式证书以支持覆盖升级。
- Windows 安装包未使用商业代码签名，系统可能提示“未知发布者”。
